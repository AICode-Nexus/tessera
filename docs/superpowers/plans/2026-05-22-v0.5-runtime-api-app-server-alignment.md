# v0.5 Runtime API App Server Alignment Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align Tessera's v0.5 runtime API / future app-server contract with typed messages, localhost-safe defaults, auth metadata, bounded event queues, generated schemas, and a no-duplicate-runtime boundary.

**Architecture:** Add provider-neutral wire DTOs to `tessera-protocol`, keep read-only event paging and SSE conversion in `tessera-core`, and expose generated TypeScript bindings through the existing `tessera-gui-bindings` path. This slice does not start an HTTP server, bind a port, execute providers through an app-server, create a daemon, freeze provider sockets, or resume background processes.

**Tech Stack:** Rust, `serde`, optional `ts-rs` bindings, `tessera-protocol`, `tessera-core`, `tessera-gui-bindings`, JSON/SSE contract tests, `git diff --check`.

---

## Scope

Implement only:

- Runtime API wire contract DTOs:
  - protocol version;
  - localhost/unix-socket bind config;
  - auth policy metadata;
  - bounded queue policy;
  - command envelope and command acknowledgement;
  - event stream request and SSE response envelope metadata.
- Core helper coverage proving `RuntimeHttpApi` remains a thin read-only adapter over `RuntimeReader`.
- Bounded in-memory runtime API event queue helper for future listener code to reuse.
- TypeScript binding generation for the new wire DTOs.
- Docs and roadmap status updates.

Do not implement:

- A listening app-server binary or crate.
- Remote non-localhost binding.
- Provider execution through HTTP.
- Tool execution, shell/file/git tools, MCP runtime, hooks, automations, or workspace mutation.
- Background reattach, daemon ownership transfer, provider socket freezing, or process survival after exit.
- Long-term auth/session storage.

fn runtime_api_event_buffer_rejects_when_full_without_dropping_existing_frames() {
    let mut buffer = RuntimeApiEventBuffer::new(1);
    let first = RuntimeSseFrame {
        id: "1".to_string(),
        event: "task_started".to_string(),
        data: "{}".to_string(),

        data: "{}".to_string(),

    let err = buffer.push(second).unwrap_err();

}
