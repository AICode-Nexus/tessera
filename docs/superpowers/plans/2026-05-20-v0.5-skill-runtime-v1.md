# v0.5 Skill Runtime v1 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tessera's first explicit, read-only Skill Runtime v1 with `SKILL.md` discovery, trace-safe activation metadata, optional read-only references, and opt-in `agent run --skill` context.

**Architecture:** Add provider-neutral skill activation metadata to `tessera-protocol`, then implement all skill filesystem discovery, parsing, redaction and context rendering in `tessera-core`. CLI gets `skills inspect` and repeatable `agent run --skill`, while TUI/GUI remain projection-only clients and no scripts/tools are executed.

**Tech Stack:** Rust, `tessera-protocol`, `tessera-core`, `tessera-cli`, JSONL trace, `sha2`, cargo contract tests, `git diff --check`.

---

## Scope

Implement only:

- project-local `SKILL.md` discovery from explicit workspace scope.
- flat frontmatter parsing for `name`, `description`, optional `version`.
- deterministic `SkillId` derivation from `name`.
- source reports, byte limits, UTF-8 handling, symlink rejection and duplicate detection.
- conservative secret-line redaction for loaded skill text and references.
- explicit skill activation with trace-safe metadata.
- optional read-only references requested by explicit relative path.
- `tessera skills inspect --workspace <path> [--json]`.
- repeatable `tessera agent run --skill <id> --workspace <path>`.

Do not implement:

- user-global skill loading.
- automatic skill activation.
- tool, shell, script, MCP, hook or automation execution.
- skill install/update/delete.
- model-driven reference selection.
- subagents, reviewer gate, swarm or learning.
- background reattach or provider socket freezing.

fn agent_run_with_skill_reports_activation_and_traces_metadata() {
    let temp = tempfile::tempdir().unwrap();
    let workspace = temp.path();
    let skill_dir = workspace.join(".tessera/skills/reviewer");
    std::fs::create_dir_all(&skill_dir).unwrap();

        skill_dir.join("SKILL.md"),
        "---\nname: reviewer\ndescription: Review safely\n---\n\nUse this skill.\n",
    )
    .unwrap();

    let output = cli_command()
        .args([
            "agent",
            "run",
            "--provider",
            "mock",
            "--goal",
            "Review this repository",
            "--skill",
            "skill_reviewer",
            "--workspace",
        ])
        .arg(workspace)
        .arg("--json")
        .output()
        .unwrap();

    assert!(output.status.success());
    let stdout = String::from_utf8(output.stdout).unwrap();
    let value: serde_json::Value = serde_json::from_str(&stdout).unwrap();
    assert_eq!(value["skill_activations"][0]["skill_id"], "skill_reviewer");

    let trace_id = value["trace_id"].as_str().unwrap();
    let records = read_trace_records(workspace, trace_id);
    let activation = records

        .find(|record| record.event_kind == "skill_activated")
        .unwrap();
    let encoded = serde_json::to_string(&activation.payload).unwrap();

}

The implementation is complete only when:

- Protocol metadata serializes without content leakage.
- Core discovers and activates skills through strict workspace boundaries.
- References are explicit, read-only, bounded and fail-closed.
- AgentLoop emits `skill_activated` before `agent_run_started`.
- CLI inspection and agent activation work in text and JSON.
- Full cargo gates pass.
- `docs/global-plan.md` and `CHANGELOG.md` reflect the completed state.

Do not claim support for executable skills, tool execution, scripts, hooks, automations, MCP runtime, user-global skill loading, subagents, background reattach, workspace mutation or default-on skill activation after this plan lands.
