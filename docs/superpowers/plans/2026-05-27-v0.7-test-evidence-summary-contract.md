# v0.7 Test Evidence Summary Contract Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a metadata-only test evidence summary contract that aggregates existing test plan/run evidence for CLI/TUI/GUI/replay inspection without executing tests.

**Architecture:** Extend protocol with a `TestEvidenceSummaryRecord` and `test_evidence_summary_recorded` event, add core validation/event construction, and project the summary into `ClientCodingWorkflow`. Keep this slice read-only and evidence-only; do not add a test runner, shell execution, checkpoint restore, or Git mutation.

**Tech Stack:** Rust workspace (`protocol`, `core`, `client`, GUI TypeScript bindings via `ts-rs`), JSONL trace events, existing coding workflow tests, Markdown roadmap docs.
