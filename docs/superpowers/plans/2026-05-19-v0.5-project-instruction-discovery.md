# v0.5 Project Instruction Discovery Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tessera's first project instruction discovery foundation with `AGENTS.md` first, `CLAUDE.md` fallback compatibility, source reporting, redaction, trace metadata and opt-in agent context.

**Architecture:** Add provider-neutral protocol metadata for instruction sources, then implement all filesystem discovery in `tessera-core`. CLI gets read-only `instructions inspect`; `agent run` can opt into instruction loading with `--instructions --workspace <path>`, while TUI/GUI remain projection-only clients.

**Tech Stack:** Rust, `tessera-protocol`, `tessera-core`, `tessera-cli`, JSONL trace, SHA-256 via `sha2`, cargo contract tests.

---

## Scope

Implement only:

- project-local instruction discovery.
- `AGENTS.md` primary source.
- `CLAUDE.md` fallback source when no `AGENTS.md` exists in the same directory.
- root-to-target broad-to-specific precedence.
- symlink rejection.
- UTF-8-safe byte limits.
- conservative line redaction.
- source metadata trace event.
- CLI inspection.
- opt-in `agent run --instructions --workspace <path>`.

Do not implement:

- user-global instructions.
- Claude import expansion.
- `.claude/` rules.
- tools, shell, file, git, HTTP, apply-patch.
- skill runtime.
- hooks or automations.
- MCP runtime.
- background task ownership or provider socket reattach.
- default-on instruction loading.

```rust
#[derive(Clone, Copy, Debug, Eq, PartialEq, Serialize, Deserialize)]
#[cfg_attr(feature = "bindings", derive(ts_rs::TS))]
#[serde(rename_all = "snake_case")]
pub enum InstructionSourceKind {
    AgentsMd,
    ClaudeMd,
}

#[derive(Clone, Copy, Debug, Eq, PartialEq, Serialize, Deserialize)]
#[cfg_attr(feature = "bindings", derive(ts_rs::TS))]
#[serde(rename_all = "snake_case")]
pub enum InstructionLoadStatus {
    Loaded,
    SkippedLowerPrecedence,
    SkippedSymlink,
    SkippedOutsideWorkspace,
    SkippedNonUtf8,
    SkippedTooLarge,
    ReadFailed,
}

#[derive(Clone, Copy, Debug, Eq, PartialEq, Serialize, Deserialize)]
#[cfg_attr(feature = "bindings", derive(ts_rs::TS))]
#[serde(rename_all = "snake_case")]
pub enum InstructionRedactionStatus {
    Clean,
    Redacted,
}

#[derive(Clone, Debug, Eq, PartialEq, Serialize, Deserialize)]
#[cfg_attr(feature = "bindings", derive(ts_rs::TS))]
pub struct InstructionSource {
    pub source_id: ContextId,
    pub kind: InstructionSourceKind,
    pub path: String,
    pub relative_path: String,
    pub precedence: u32,
    pub placement: ContextPlacement,
    pub status: InstructionLoadStatus,
    pub original_bytes: u64,
    pub loaded_bytes: u64,
    pub sha256: Option<String>,
    pub redaction_status: InstructionRedactionStatus,
    pub warnings: Vec<String>,
}
```
