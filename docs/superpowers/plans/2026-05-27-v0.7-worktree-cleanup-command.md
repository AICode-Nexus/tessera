# v0.7 Worktree Cleanup Command Implementation Plan

> **For agentic workers:** Use `using-git-worktrees` for isolation and `test-driven-development` for code changes. Keep this slice narrow: cleanup retained Tessera-generated detached worktrees only.

**Goal:** Add `tessera worktree cleanup` so an operator can remove a retained generated worktree using trace lifecycle evidence plus an explicit local path.

**Architecture:** CLI resolves config/data dir and source root, reads trace lifecycle records, validates that the requested worktree was created and retained by Tessera, then delegates a single non-force `git worktree remove <path>` call through the fixed core runner. Trace remains path-redacted.

**Tech Stack:** Rust workspace (`cli`, `core`, existing `protocol` event types), JSONL `TraceStore`, Clap, tempdir CLI contract tests, Markdown docs.
