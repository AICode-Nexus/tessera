# v0.6 Subagent Transcript Artifact Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add provider-neutral, trace-backed lifecycle metadata for sub-agent transcript artifact handles before any child-agent execution.

**Architecture:** Extend `tessera-protocol` with transcript artifact lifecycle DTOs and a stable event kind, add a non-executing core helper that validates lifecycle records, and project the metadata read-only through `tessera-client` and GUI bindings. The slice records artifact-handle state only; it does not store transcript bodies, call providers, execute tools, schedule children, or mutate workspaces.

**Tech Stack:** Rust, `serde`, `ts-rs`, `tessera-protocol`, `tessera-core`, `tessera-client`, `tessera-gui-bindings`, Markdown docs, `cargo fmt`, `cargo clippy`, `cargo test`, `git diff --check`.

---

## Scope

Implement only:

- `SubagentTranscriptArtifactStatus` and `SubagentTranscriptArtifactLifecycleRecord`.
- `RunEvent::SubagentTranscriptArtifactLifecycleRecorded`.
- A non-executing core lifecycle helper for reserve/publish/seal/abandon metadata.
- Read-only client and GUI projection of lifecycle records.
- Contract docs and roadmap updates.

Do not implement:

- Provider-backed child-agent execution.
- Scheduler/fan-out/swarm runtime.
- Transcript body storage, summarization, retention, or parent context ingestion.
- Tool execution, shell/file/git execution, apply-patch, or workspace mutation.
- App-server listener, daemon, hook runtime, automation runtime, or MCP runtime.
