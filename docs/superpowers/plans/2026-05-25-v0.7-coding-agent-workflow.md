# v0.7 Coding-Agent Workflow Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add provider-neutral, metadata-only v0.7 coding-agent workflow contracts for patch proposals, diff/test evidence, checkpoint requirements, review bundles, restore plans, and worktree-first mutation boundaries.

**Architecture:** Start with protocol DTOs/events and replayable projection, then add a non-executing core coordinator that validates gate ordering and returns `RunEvent` values only. CLI/TUI/GUI/runtime API remain clients over projected state; no file mutation, shell execution, apply-patch execution, checkpoint restore, or Git mutation is allowed in this plan.

**Tech Stack:** Rust workspace (`protocol`, `core`, `client`, `gui-bindings`), serde/ts-rs DTO generation, JSONL trace projection, contract tests, docs.
